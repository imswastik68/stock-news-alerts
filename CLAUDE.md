# stock-news-alerts session log

Read `SESSION_LOG.md` before starting any work here — it has current
architecture, recent fixes, and open items that git log doesn't explain.
`ROADMAP.md` is the forward plan: what's left, in priority order, with the
evidence behind each item. Read it before proposing improvements — the top
priority is usually not the one that looks most interesting from the code.

At the end of any session that changes code or config in this repo, add an
entry to the top of the `## Log` section in `SESSION_LOG.md`: what changed,
why, what was verified, what's still open. If a change updates something
already described in "Current Architecture" or "Known structural limits",
edit that section in place instead of leaving it stale.
